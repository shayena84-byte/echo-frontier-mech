# Рубеж Эха

Однопользовательская браузерная стратегия на изометрической карте. Отряд мехов пережил аварийную посадку в каньоне Вектра. Захватите станции и удержите их 24 секунды, чтобы передать сигнал эвакуации. Второй путь к победе — уничтожить Цитадель дронов. Потеря лагеря завершает операцию поражением.

## Играть

Откройте сайт проекта через GitHub Pages или загрузите файлы репозитория и откройте `index.html` в современном браузере. Игра работает без сервера, установки зависимостей и подключения к сторонним сервисам.

| Действие | Управление |
| --- | --- |
| Выбрать меха | Щелчок по меху или его карточке, клавиши `1`–`8` |
| Выбрать несколько | `Shift` + щелчок по меху или карточке |
| Выбрать всех | `G` или кнопка в панели отряда |
| Переместиться | Щелчок по земле, станции или кнопке станции |
| Выбрать цель для атаки | Щелчок по дрону или вражеской базе |
| Поставить на паузу | `Пробел` или кнопка в верхней панели |
| Сменить темп игры | Кнопки скорости `1` (0,5×), `2` (1×), `3` (2×) в верхней панели |
| Собрать меха | `F` или кнопка в мастерской |

Таймеры показывают игровое время. При смене скорости движение, бой, захват, производство и наступление дронов ускоряются или замедляются вместе.

Мехи автоматически атакуют врагов в пределах дальности оружия. Выбранные юниты можно отправить на ремонт в лагерь. Сплав, энергия и данные поступают из лагеря и захваченных станций. Ходовая, оружие и модуль влияют на характеристики и внешний вид меха. Новую конфигурацию видно в мастерской до сборки.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Интерфейс, игровой холст и справка |
| `style.css` | Оформление и адаптивная раскладка |
| `simulation.js` | Карта, поиск пути, экономика, захват, бой и ИИ |
| `renderer.js` | Изометрический рендеринг на Canvas 2D |
| `mech-art.js` | Объёмные модели ходовой, оружия и оборудования |
| `app.js` | Ввод, звуковые эффекты и интерфейс |

Для публикации копии через GitHub Pages укажите в настройках Pages ветку `main` и каталог `/ (root)`.
