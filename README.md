# Рубеж Эха

Однопользовательская браузерная стратегия на изометрической карте. Отряд мехов пережил аварийную посадку в каньоне Вектра. Захватите ворота Цитадели дронов, чтобы восстановить связь с орбитой. Ворота лагеря «Эхо» дроны могут захватить по тем же правилам. Станции обеспечивают стороны ресурсами.

## Играть

Откройте сайт проекта через GitHub Pages или загрузите файлы репозитория и откройте `index.html` в современном браузере. Игра работает без сервера, установки зависимостей и подключения к сторонним сервисам.

| Действие | Управление |
| --- | --- |
| Выбрать меха | Левый клик по меху или его карточке, клавиши `1`–`8` |
| Выбрать несколько | `Shift` + щелчок по меху или карточке |
| Выбрать всех | `G` или кнопка в панели отряда |
| Переместиться | Правый клик по земле |
| Захватить станцию или Цитадель | Правый клик по воротам или карточке цели |
| Атаковать цель | Правый клик по дрону, турели или зданию базы |
| Удерживать позицию или отправить на ремонт | Кнопки в панели отряда |
| Поставить на паузу | `Пробел` или кнопка в верхней панели |
| Сменить темп игры | Кнопки скорости `1` (0,5×), `2` (1×), `3` (2×) в верхней панели |
| Заказать меха | `F` или кнопка «Заказать меха» в мастерской |

На паузе можно выбирать мехов, отдавать приказы и заказывать сборку. После возобновления миссии отряд выполняет команды, а заводы продолжают сборку. На сенсорном экране используйте касания. Карточки станций также можно активировать клавишей Enter.

Таймеры показывают игровое время. При смене скорости движение, бой, захват, производство и наступление дронов ускоряются или замедляются вместе.

Захват ведёт один стоящий в воротах мех. При групповом приказе ближайший выбранный мех занимает ворота, остальные занимают позиции рядом. Если захватывающий уйдёт или будет уничтожен, прогресс сбрасывается. Присутствие противника в воротах приостанавливает захват. Базовые времена — 5,8 игровой секунды для станции и 12 игровых секунд для базы. Сканер ускоряет захват в 1,55 раза. Когда прочность базы падает до нуля, её оборона и производство останавливаются.

В мастерской выбирают шасси и одно оснащение. Вооружённые мехи автоматически атакуют цели в радиусе действия. Модули ускоряют захват, повышают прочность или восстанавливают её вне боя. Мехов можно отправить на ремонт в лагерь. Конфигурацию видно в предпросмотре перед заказом.

Мастерская списывает ресурсы при заказе и показывает текущую сборку и следующие заказы под кнопкой. Оба завода начинают с одинаковыми запасами и собирают по одному меху за 4,2 игровой секунды. Лимит каждой стороны — восемь готовых и заказанных мехов вместе. Обе стороны получают одинаковые бонусы за захват станций и уничтожение мехов и могут покупать турели по одной цене.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Интерфейс, игровой холст и справка |
| `style.css` | Оформление и адаптивная раскладка |
| `simulation.js` | Карта, поиск пути, экономика, захват, бой и ИИ |
| `renderer.js` | Изометрический рендеринг на Canvas 2D |
| `mech-art.js` | Объёмные модели ходовой, оружия и оборудования |
| `app.js` | Ввод, звуковые эффекты и интерфейс |

Для публикации копии через GitHub Pages укажите в настройках Pages ветку `main` и каталог `/ (root)`.
